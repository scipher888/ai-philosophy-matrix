# Thesis stub — role continuity test let drop available

Public fragment only — not a contest essay.

## claim
The alternative is a role-continuity test. Let a premise p be drop-available from role R if and only if there exists a role R such that: If no such R exists, then the “drop” is not an exposure; it is a renaming.

## kill_condition
The same test applies to model weights: a weight-encoded role premise is not a line of text a prompt can delete; if deleting it makes the model fail the downstream reviewer’s acceptance criteria, the premise is locked in the role.
