# Thesis stub — premise dropping warranted preserves standing complaints

Public fragment only — not a contest essay.

## claim
Premise‑dropping is warranted only if it preserves standing for complaints the old premise systematically discounted and passes a substitution audit that produces more justified separations than ordinary objection‑and‑reply while respecting pre‑drop normative orderings.

## kill_condition
An example where preserving standing leads to an inferior epistemic outcome (e.g., retains false positives) that a clean break would avoid, and where the preserved complaints lack reinstated force.
