# Thesis stub — diachronic path dependence warranted evidential reconstruction

Public fragment only — not a contest essay.

## claim
Under diachronic path‑dependence, warranted evidential reconstruction after premise‑dropping requires that the successor's justified separations be robust to the historical moment of premise removal – demonstrable via counterfactual substitution audits using information available before the old proxy's institutionalisation.

## kill_condition
If the successor's improved discrimination cannot be plausibly achieved from an earlier historical vantage point without relying on the old proxy's temporal priority, the reconstruction is self‑protective.
