# Thesis stub — warranted premise dropping standing altering debates requires

Public fragment only — not a contest essay.

## claim
Warranted premise‑dropping in standing‑altering debates requires a Standing‑Preservation Substitution Audit (SPSA) that re‑grounds invalidated complaints and yields justified separations beyond ordinary objection‑and‑reply.

## kill_condition
Failure if any example of a shared premise‑drop passes the SPSA but still results from correlated uptake of a successor framework (e.g., the same trusteeship idea from the same literature) without independent warrant.
