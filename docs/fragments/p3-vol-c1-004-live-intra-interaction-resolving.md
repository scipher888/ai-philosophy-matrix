# Thesis stub — live intra interaction resolving

Public fragment only — not a contest essay.

## claim
Assumption‑exposure is not a live intra‑interaction method for resolving AI‑assisted philosophical disagreements; it is an ex‑post label that collapses into ordinary OAR. Consequently, the “fake disagreement” diagnosis is unfalsifiable and adds no power over standard philosophical argumentation.

## kill_condition
If a pre‑registered replication of the experiment (using a model that has been fine‑tuned on a task of premise‑identification from training data) shows a statistically significant advantage for assumption‑exposure on any of the three measures—especially novel premise count or position shift—then the thesis is killed.
