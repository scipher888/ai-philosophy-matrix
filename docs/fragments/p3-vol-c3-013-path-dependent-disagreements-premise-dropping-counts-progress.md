# Thesis stub — path dependent disagreements premise dropping counts progress

Public fragment only — not a contest essay.

## claim
In path‑dependent disagreements, premise‑dropping counts as progress iff it identifies a counterfactual fork where dropping the premise would alter subsequent reasoning and improve case discrimination, with the fork independently verifiable via structural breaks.

## kill_condition
No stable, case‑discriminating fork is found for any candidate premise in a given path‑dependent disagreement.
