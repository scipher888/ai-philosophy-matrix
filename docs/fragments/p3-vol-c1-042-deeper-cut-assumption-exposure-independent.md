# Thesis stub — deeper cut assumption exposure independent

Public fragment only — not a contest essay.

## claim
Under the deeper cut, assumption-exposure is not an independent method: any shared inherited premise it can target is either already targetable as an ordinary shared-premise objection by OAR, or it is a default temporal-initiation anchor that AE cannot drop because its own instruction must be initiated by one party; therefore the “fake disagreement, drop and rebuild” claim is unfalsifiable unless a pre-registered paired protocol shows an order-invariant verdict distinct from matched OAR.

## kill_condition
The thesis is killed if a pre-registered run of the protocol shows that AE robustly identifies the same inherited premise regardless of initiator order, that OAR flags a different premise in most cases, and that AE’s final verdict is distinct from OAR in more than 15/20 cases.
