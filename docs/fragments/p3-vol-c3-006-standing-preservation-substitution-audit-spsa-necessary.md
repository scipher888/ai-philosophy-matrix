# Thesis stub — standing preservation substitution audit spsa necessary

Public fragment only — not a contest essay.

## claim
Standing-Preservation Substitution Audit (SPSA) is necessary for warranted premise‑dropping when the old premise was standing‑constitutive for systematically disadvantaged complainants; it passes iff (i) preserves complaint identity without borrowing old proxy authority, (ii) beats equally resourced OAR on justified separations, (iii) is diachronically stable.

## kill_condition
A single matched‑case OAR trial that produces equal or greater justified separations than the SPSA reconstruction, with blind scoring, without the SPSA’s standing‑preserving procedures, **or** a case where the SPSA‑compliant reconstruction nevertheless systematically silences the same set of actors as the old premise.
