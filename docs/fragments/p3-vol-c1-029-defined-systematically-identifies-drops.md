# Thesis stub — defined systematically identifies drops

Public fragment only — not a contest essay.

## claim
> The assumption‑exposure protocol, as defined, systematically identifies and drops inherited epistemic‑virtue anchors (tacit criteria) that are shared between human prompts and model defaults; this yields a different verdict about foundational premises from matched ordinary OAR in a pre‑registered majority of trials, thereby falsifiably showing that such anchors are a binding constraint and that dropping them reorients what counts as progress in AI‑assisted philosophy.

## kill_condition
Replication failure: A blinded, independent run of the protocol with a different set of 10 trials fails to show a majority (≥6/10) of different verdicts, or the stop‑rule is not met. - Anchor‑irrelevance: It is shown that the anchors on the checklist are not actually shared between human prompts and model defaults (e.g., the model does not consistently rank parsimony).
