# Thesis stub — disagreements embedded diffuse assumption ecology exposure

Public fragment only — not a contest essay.

## claim
For disagreements embedded in a diffuse assumption‑ecology, “exposure/drop/rebuild” is coherently defined by a substitution audit (improved case discrimination against a premise‑retention baseline), and this audit provides warrant regardless of the successor’s genealogy.

## kill_condition
If no paired cases can be found where the original premise forces a ranking that the successor reverses and improves; or if a matched OAR baseline yields equal or greater case discrimination.
