# Thesis stub — dropping institutionally embedded false premise

Public fragment only — not a contest essay.

## claim
Dropping an institutionally embedded false premise destroys a truth-seeking division of labour unless a counter-mandated opposition role is installed; such a role preserves adversarial search via shadow-budget substitution audits, not by defending the old premise.

## kill_condition
A live institutional case where the old premise is dropped and unrestricted objection-and-reply continues to produce the same case separations without a mandated opposition role.
