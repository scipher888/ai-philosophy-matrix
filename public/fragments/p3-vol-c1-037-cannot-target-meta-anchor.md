# Thesis stub — cannot target meta anchor

Public fragment only — not a contest essay.

## claim
Assumption‑exposure cannot target a shared inherited meta‑disagreement anchor when the premise in question is weight‑encoded as an institutional override that cannot be dropped without dissolving the institution; in such cases the “fake” diagnosis becomes unfalsifiable because the anchor functions as a structural constraint rather than a negotiable belief, and the exposure protocol merely highlights a lock that was never part of the shared training inheritance.

## kill_condition
Show a case where the premise in question is not inherited from any training data or literature but is a logical necessity of the institution’s function – e.g., “a command hierarchy must have a single ultimate decision point.” If that premise has no textual training origin but is a structural requirement, then assumption‑exposure cannot target it as an inherited premise, and the protocol’s diagnostic claim collapses.
