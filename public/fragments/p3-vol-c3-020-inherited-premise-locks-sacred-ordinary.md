# Thesis stub — inherited premise locks sacred ordinary

Public fragment only — not a contest essay.

## claim
The inherited premise that locks the sacred/ordinary boundary is a temporal-procedural default (the framework travels unless proven exceptional). Dropping it warrants a replacement by inverting the directional load (proponent must demonstrate non-exceptionality), passing a TLISSA that produces a justified separation robust across historical path variation.

## kill_condition
Failure if TLISSA case rankings are identical to the original default’s order for a tested set, or if the inversion cannot be replicated from a different temporal starting point in simulation.
