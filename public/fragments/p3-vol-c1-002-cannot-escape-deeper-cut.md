# Thesis stub — cannot escape deeper cut

Public fragment only — not a contest essay.

## claim
> Assumption‑exposure cannot escape the deeper‑cut collapse into ordinary OAR: any operational test that tries to distinguish them will fail to find a difference, because “dropping a training‑inherited premise” is an instruction that the fixed‑weight model can only simulate via standard argumentative moves, and the resulting outputs are indistinguishable from OAR in both novelty and dispute‑resolution.

## kill_condition
If a preregistered test using the protocol in §1 reveals a statistically significant (p < 0.01 after correction) and practically meaningful effect (Cohen’s d > 0.5) in either novelty or disagreement reduction favouring assumption‑exposure over OAR, and if that effect cannot be accounted for by simple framing confounds (e.g., the AE instruction producing longer outputs that mechanically increase embedding distance), then my thesis is falsified.
