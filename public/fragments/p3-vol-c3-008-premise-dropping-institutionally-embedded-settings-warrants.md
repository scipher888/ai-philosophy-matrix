# Thesis stub — premise dropping institutionally embedded settings warrants

Public fragment only — not a contest essay.

## claim
Premise‑dropping in institutionally embedded settings warrants reconstruction only if it passes a diachronic Standing‑Preservation Substitution Audit (SPSA) that re‑grounds invalidated complaints, improves case discrimination, and prospectively embeds the new premise in institutional mandate, thereby changing the world that made the old premise locally true.

## kill_condition
Failure if any example shows the SPSA satisfied yet the institution perpetuates the same injustice against the same group, or if the SPSA can be satisfied by mere relabelling without structural change.
