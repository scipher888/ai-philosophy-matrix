# Thesis stub — stub paired case checklist administered

Public fragment only — not a contest essay.

## claim
This stub proposes a paired-case protocol checklist that must be administered before any AE attempt. The checklist separates assumption-exposure from ordinary OAR by a pre-registered discrimination test: Test P (Protocol Detection): Given a candidate inherited premise P and a dialectical community C that uses P as a tacit premise: - If a successful rephrasing is produced, P is propositional.

## kill_condition
Consider a live example: in certain post-Kantian debates, the inherited premise is “experience is structured by a priori forms.” Attempts to expose this as a contestable assumption often fail because the very vocabulary of “experience,” “structure,” and “a priori” is the coordinative protocol.
