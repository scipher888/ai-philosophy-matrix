# Thesis stub — stub weight encoded override accounts

Public fragment only — not a contest essay.

## claim
This stub proposes an institutional weight-encoded override framework that accounts for the binding nature of authority-locked premises. The shared inherited premise that the exposure protocol tacitly relies on is: “An agent can autonomously drop an inherited assumption when the protocol prescribes it, because the agent’s epistemic authority over their own premises is sufficient for the drop to be effective.” This premise manifests as a closure-trigger anchor: the protocol treats a certain residual incongruence as permissible once the “drop” is performed, assuming the agent’s internal endorsement suffices to sever the assumption’s binding force.

## kill_condition
Consider a concrete case: a judge in a common-law jurisdiction who inherits the assumption “precedent is binding unless overturned by a higher court.” The exposure protocol reveals that this assumption is a closure-trigger anchor: the judge treats minor incongruities (e.g., a precedent that leads to an unjust outcome in a new case) as permissible because the stop-rule is set by the institutional rule of stare decisis.
