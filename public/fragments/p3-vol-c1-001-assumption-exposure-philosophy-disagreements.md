# Thesis stub — assumption exposure philosophy disagreements

Public fragment only — not a contest essay.

## claim
Assumption-exposure in AI philosophy disagreements is recursively unstable: any inherited premise it claims to expose is either already accessible via ordinary OAR, or the exposure method’s own analytic premise is itself an inherited premise from the same literature/training ecology.

## kill_condition
The thesis would be killed if an actual run of the protocol (using human experts, not LLMs, for fairness) produced (a) a premise uniquely identified by assumption-exposure that (b) is not in the candidate set and is not accessible to OAR, and (c) the method premise used by assumption-exposure is itself not a member of the candidate set (i.e., it is a genuinely novel analytic frame not found in the training/literature ecology).
